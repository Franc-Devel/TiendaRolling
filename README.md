# Tienda Rolling · Demo educativa con React

Aplicación de aprendizaje con React y Vite, catálogo, administración de productos y persistencia en el navegador.

## Dónde está el código

La rama principal contiene documentación. La implementación está en [dev](https://github.com/Franc-Devel/TiendaRolling/tree/dev), con componentes, contextos y páginas para catálogo y administración.

## Ejecución local de la rama dev

```bash
git clone --branch dev https://github.com/Franc-Devel/TiendaRolling.git
cd TiendaRolling
npm ci
npm run dev
```

Los scripts y dependencias están en el package.json de esa rama. Abrir la URL indicada por Vite.

## Alcance y límites

Demo frontend de formación. La persistencia local no equivale a una base de datos compartida ni a autorización de servidor. Usar datos ficticios y no emplearla para ventas reales.

La rama dev se enlaza para revisión; no se integra a main ni se cambia la rama por defecto. El historial conserva las contribuciones originales.
